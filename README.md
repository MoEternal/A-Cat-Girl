## 🐾 项目简介

《一只猫娘》（**A Cat Girl**）是一套将 AI 角色聊天能力接入通讯软件的连接与配置管理程序。项目目标是让同一套模型、人设、提示词、世界书和插件能力可以通过通讯软件使用，目前首先完成的是 QQ / NapCat。

当前版本中，QQ 是已经可用的聊天入口，网页控制台负责配置、管理和检查运行状态。你可以在后台切换模型供应商，编辑实际发送给模型的提示词顺序，维护用户人设、角色人设和世界书，并为不同 QQ 私聊或群聊保存相互隔离的聊天记录。其他通讯软件仍属于后续接入方向，不作为 v1.0.0 的现有功能宣传。

项目并不限定角色必须是“猫娘”。名称代表最初的角色陪伴用途，实际可以创建和切换不同人设，也可以通过组合预设为每套角色配置独立的模型、提示词、用户人设和世界书。

公开发行包只包含项目自带的公开插件，不包含柏宝书、私人记忆、账号、API Key、数据库、日志或其他本地运行数据。

## 🎯 核心工作流

1. **配置模型 API** —— 添加供应商、API 地址、Key 和模型，必要时设置故障转移顺序。
2. **建立角色配置** —— 创建或导入提示词、用户人设、角色卡与世界书，并组合成一套预设。
3. **连接 NapCat** —— 在 QQ 连接页面完成 OneBot 配置，由 QQ 私聊或群聊接收消息。
4. **按需启用插件** —— 使用分段回复、同步撤回、时间感知、记忆、网络搜索等扩展能力。
5. **持续维护数据** —— 在网页中切换聊天记录、导出配置，并按需备份数据库和文件记忆。

## ✨ 主要功能

- **QQ / NapCat 接入：** 支持 OneBot 11 反向 WebSocket、私聊与群聊开关、允许名单、消息去重、图片接收和待发送动作恢复。
- **多模型供应商：** 支持 OpenAI 兼容、Anthropic 与 Google/Gemini 协议，可拉取模型列表并设置供应商故障转移顺序。
- **组合预设：** 将 API 供应商、提示词模板、用户人设、角色人设、世界书和生成参数组合成一套可切换配置。
- **提示词工作台：** 提示词块支持角色、启停、拖拽排序、深度插入、动态标识符、折叠收纳和实际发送预览。
- **角色与用户人设：** 用户身份和 AI 角色相互独立，可分别设置描述、注入位置和关联资源。
- **世界书：** 支持主关键词、辅助关键词、常驻/选择性触发、概率、插入位置、深度、顺序及角色/全局作用范围。
- **多聊天记录：** 同一个 QQ 私聊或群聊可以创建多份互相隔离的记录，并随时切换当前使用的时间线。
- **文件与图片安全：** QQ 图片经过类型、大小、像素和数量检查；聊天历史不保存图片 Base64 数据。
- **统一导入导出：** 支持导入常见 SillyTavern 预设、角色卡和世界书格式，并可导出预设、API、提示词、人设、聊天记录和记忆状态。
- **公开插件系统：** 内置功能与第三方插件使用同一套插件接口，支持设置、状态、动作、定时任务和管理页面扩展。

## 🧩 内置插件

正式版包含以下 10 个公开插件：

| 插件 | 默认状态 | 作用 |
|---|---:|---|
| 正则 | 开启 | 按全局或角色规则处理发送到 QQ 的模型回复。 |
| 同步撤回 | 开启 | 用户在有效窗口内撤回消息后，同步撤回对应 AI 回复。 |
| 记忆系统（测试） | 关闭 | 维护角色档案、关系、事件、约定、物品和长期剧情记忆。 |
| 回复合并 | 开启 | 合并用户短时间内连续发送的消息，实现用户端分段输入。 |
| 分段回复 | 开启 | 将模型的一次回复按自然停顿拆分发送，第一段不额外延迟。 |
| 主动回复 | 关闭 | 在用户长时间没有回复时，由角色主动发起后续对话。 |
| 表情回复 | 关闭 | 根据模型回复选择并发送本地表情图片。 |
| 时间感知 | 开启 | 向模型提供部署环境的本地日期、星期、时段和消息间隔。 |
| 睡眠模拟 | 关闭 | 双方互道休眠关键词后暂存消息，并在醒来时统一回复。 |
| 网络搜索 | 关闭 | 通过搜索模型或网页搜索源获取资料，再交给当前角色回答。 |

第三方 Python 插件与主程序运行在同一进程权限下，并不是安全沙箱。只安装来源可信、内容可审查的插件。

## 📥 支持的导入格式

- SillyTavern Chat Completion 预设 JSON
- V1、V2、V3 角色卡 JSON
- 带 `chara` 或 `ccv3` 元数据的角色卡 PNG
- 独立世界书 JSON
- 角色卡内嵌世界书

角色卡 PNG 当前导入文本设定和内嵌世界书，不保存卡片立绘。导入时无法识别或超出项目能力范围的字段会在结果中提示，不会静默写入未知配置。

## 📦 下载与版本选择

正式发行文件请前往仓库的 [Releases](../../releases) 页面下载。每个版本同时提供 `SHA256SUMS.txt` 用于校验文件完整性。

| 平台 | 文件 | 启动方式 |
|---|---|---|
| Windows 桌面版 | `A-Cat-Girl-v1.0.0-windows-x64.zip` | 解压整个目录后运行 `A Cat Girl.exe`。 |
| Windows 网页版 | `A-Cat-Girl-v1.0.0-windows-web-x64.zip` | 解压后双击 `启动一只猫娘.cmd`。 |

### Windows 桌面版

适合普通 Windows 10/11 桌面环境。程序通过 WebView2 显示管理界面；如果系统没有 WebView2 Runtime，需要从微软官方安装后再启动。`data`、`logs` 和 `backups` 保存在程序目录中，更新时不要删除。

### Windows 网页版

适合服务器或不需要桌面壳的 Windows 环境。首次启动会联网安装 `uv`、Python 3.12 和锁定依赖，服务就绪后自动打开浏览器。需要局域网访问时，应先在服务器本机创建管理员账号，再启用局域网监听并限制防火墙来源。

### Linux 网页版

首次启动会安装 `uv`、Python 3.12 和锁定依赖。默认只监听 `127.0.0.1:8732`；远程使用建议通过 SSH 隧道或可信反向代理访问，不要直接将管理端口暴露到公网。

## 🚀 快速开始

1. 下载对应平台的发行包，并完整解压到本地目录。
2. 启动程序，首次打开时创建管理员账号。
3. 进入“API配置”，填写模型服务地址、API Key 和模型名称。
4. 在“提示词编辑”“用户人设”“角色人设”和“世界书”中准备所需资源。
5. 在“预设配置”中选择这些资源并保存整套预设。
6. 进入“QQ连接”，按照页面显示的信息配置 NapCat 和 OneBot 连接。
7. 根据需要启用记忆系统、主动回复、表情回复、睡眠模拟或网络搜索。

QQ 访问令牌是可选项：未配置时不会强制 NapCat 提供令牌；一旦配置，连接必须严格匹配。

## 🔐 数据与安全

主要持久数据位于程序目录的 `data/`：

```text
data/catgirl.db
data/secret.key
data/plugin_memory/
data/media/
data/plugins/
```

- `catgirl.db` 保存账号、配置、聊天记录和普通插件状态。
- `secret.key` 用于加密已保存的 API Key，恢复数据库时必须一并恢复。
- `plugin_memory/` 保存记忆系统等插件的文件记忆。
- `media/` 保存经过安全处理的 QQ 图片。
- `plugins/` 保存用户安装的第三方插件，不包含项目自带插件。

SQLite 使用 WAL 模式。迁移数据库前应先停止程序，并将 `catgirl.db`、`catgirl.db-wal` 和 `catgirl.db-shm` 作为一组处理。

API 配置导出文件包含完整 API Key，只能保存到可信目录。管理后台使用 HttpOnly 会话 Cookie；即使已经设置管理员密码，也不应把管理端口直接开放到互联网。

## 🌐 网络搜索说明

网络搜索支持独立搜索模型、SearXNG、DuckDuckGo、Google、SerpApi 和 Bing。

使用独立搜索模型时，应选择本身具备联网搜索能力的模型。程序会向搜索模型提供部署环境的本地时间和本次查询，再将检索材料交回主模型生成角色回复。“结果数量”只控制网页搜索源，不限制独立搜索模型返回的内容。

相同搜索方式、端点/模型和关键词会在当前程序进程内缓存 10 分钟，避免短时间重复请求搜索服务；主模型仍会针对每轮对话重新生成最终回复。程序重启后缓存自动清空。

## 🛠️ 本地开发

项目使用 Python 3.12、FastAPI、Vue 3、TypeScript 和 SQLite。

Windows 开发环境可运行：

```powershell
& '.\scripts\bootstrap.ps1'
& '.\scripts\start.ps1'
```

常用检查命令：

```powershell
.\.venv\Scripts\python.exe -m pytest

Set-Location frontend
npm run typecheck
npm run build
npx playwright test
```

一次构建全部公开发行包：

```powershell
& '.\scripts\package-public.ps1'
```

公开打包流程会拒绝柏宝书、私人附加清单、数据库、密钥、日志、备份和导入数据进入正式包。
