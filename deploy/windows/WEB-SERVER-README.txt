一只猫娘 v1.0.1 Windows 网页版

1. 解压整个目录，不要直接在 ZIP 内运行。
2. 双击根目录“启动一只猫娘.cmd”。首次运行会联网安装 uv、Python 3.12 和锁定依赖。
3. 服务就绪后会自动打开 http://127.0.0.1:8732/，首次打开需要创建管理员账号。
4. 默认只允许本机访问。需要局域网访问时，先在本机创建管理员账号，再运行 deploy\windows\初始化为局域网访问.cmd。
5. 此公开版只包含内置插件，不包含私人插件或运行数据。

局域网模式必须用 Windows 防火墙限制来源地址，不要把 8732 端口直接暴露到公网。
