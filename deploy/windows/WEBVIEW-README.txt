一只猫娘 v1.0.0 Windows WebView 版

1. 解压整个目录后运行“A Cat Girl.exe”，不要只复制 EXE。
2. data、logs、backups 均保存在 EXE 同级目录，更新时不要删除这些目录。
3. 如果系统缺少 WebView2，请运行包内的 MicrosoftEdgeWebview2Setup.exe。
4. 首次打开需要创建管理员账号；本地接口只监听 127.0.0.1:8732。
5. 此公开版只包含内置插件，不包含任何私人运行数据。

Windows Server 必须具有桌面体验。纯命令行环境请使用 Windows 网页版或 Linux 版。
