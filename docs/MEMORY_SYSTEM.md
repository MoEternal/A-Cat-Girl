# 记忆系统

`memory_system` 是“一只猫娘”的原创内置插件，面向单人或多人长篇剧情：情感/恋爱主线，以及战斗、探索、悬疑、日常等任意支线。

插件仍标记为测试版 / beta，但在公开版中默认启用。核心角色名称可以留空，由剧情自动识别；也可以填写一个或多个需要优先保持连续性的角色。插件使用当前组合预设的 API 供应商，不保存独立 API Key。

## 每轮流程

1. 用户消息到达后，插件从当前聊天记录的台账中挑选相关长期记忆。
2. 情感主线、核心角色当前状态、未完成承诺和永久固定事实优先注入。
3. 模型生成正常回复。
4. 插件静默调用一次当前供应商，把本轮剧情整理为结构化台账；分析结果不发送到 QQ，也不写入聊天历史。
5. 默认每 8 轮额外回看近期原文，补记第一次整理遗漏的衣着、伤势、物品、能力、秘密、线索、地点与时间等细节。
6. 旧事件超过阈值后压缩为远期篇章；人物状态、事实、承诺、物品和秘密知情范围不会随事件摘要一起删除。

静默整理意味着每轮通常会比未启用插件多一次模型调用；到达补漏或压缩轮次时还会增加一次。可在插件设置中调整或关闭补漏。

## 记忆结构

- 恋爱主线：阶段、当前状态、核心矛盾和未解决压力。
- 人物台账：核心/主要/配角、关系阶段、好感、信赖、嫉妒、衣着、伤势、情绪、目标和关键节点。
- 主观记忆：记忆属于谁、哪些角色知情、是否私密。
- 支线：战斗、探索、悬疑、日常、成长等类型及未解决事项。
- 连续性事实：身份、外貌、伤势、能力、关系、线索、地点和时间。
- 承诺：参与者、知情人以及待完成/兑现/违背/取消状态。
- 物品：持有者、数量或状态、所在位置。
- 事件与远期篇章：近期保留独立事件，久远内容分层压缩。

好感等数值只用于保持变化方向，不代替剧情证据。补漏审计不会重复累计同一次关系变化。

## QQ 命令

```text
/记忆帮助
/记忆状态
/记忆角色
/记忆支线
/记忆核心 名称1,名称2
/记忆核心 清除
/记忆固定 需要永久保留的事实
/记忆清除 确认
```

`/记忆核心` 只覆盖当前聊天记录；插件页面中的核心角色名称是其他记录的默认值。留空或执行 `/记忆核心 清除` 后按剧情自动识别。指定核心角色只提高常驻召回优先级，不决定感情结局。`/记忆清除 确认` 只清除当前这份记录，不能影响同一 QQ 的其他时间线。

## 数据与安全

- 每份聊天记录默认建立并绑定一份独立 JSON 记忆；空聊天记录也可以先建记忆，收到第一句话时同样会自动建立。
- 可在插件页手动把任意记忆绑定到其他聊天记录。共享记忆的整理按记忆 ID 串行，避免并发覆盖。
- 记忆正文位于 `data/plugin_memory/memory_system/memory_records/memories/`，停止程序后可直接编辑；下次读取以文件内容为准。
- 撤回仅在文件仍是该回合写出的版本时回退；若其他聊天或手工编辑已改动，保留当前文件并把快照放入 `rollback_conflicts/`。
- 静默模型调用拒绝图片 data URI，且不写入正式聊天历史或待发送动作。
- 插件只读取最多 200 条安全文本历史；当前默认补漏窗口远小于该上限。

该插件没有复制其他记忆扩展的源码、表结构、提示词格式、前端素材或存储格式。
